# 要件定義書

## 1. プロジェクト概要

- 背景: 送迎者が変わるときにわかりやすくするため
- 目的: LINE で連絡を取らずに、ポップアップで通知が来て分かりやすく
- スコープ
  - 含むもの: 1 週間分（今週・来週）の送る人と行先の一覧、日ごとのメモ、曜日ごとの固定の行先の設定、変更のプッシュ通知
  - 含まないもの: お迎えの担当、子どもごとの管理、先週より前の記録の閲覧、家族ごとのアカウント

## 2. ユーザーストーリー

As a 自分と家族
I want 子どもの送迎者が一覧で確認できる
So that 知りたい情報をいつでも簡単に確認できる

## 3. 機能要件

| ID   | 機能名     | 説明                                                                                                         | 優先度 | Phase |
| ---- | ---------- | ------------------------------------------------------------------------------------------------------------ | ------ | ----- |
| F-01 | 送る人     | 押すだけ、「パパ」「ママ」押すと光る、もう一度押すと消える                                                   | 高     | MVP   |
| F-02 | 行先       | 自動で入力される、毎週固定の行先を設定できる、設定画面で変更可能                                             | 高     | MVP   |
| F-03 | ボタンの色 | 「パパ」青「ママ」ピンク                                                                                     | 中     | v2.0  |
| F-04 | 詳細       | 行先がリンクになり、押すと詳細が記載できる。メモ欄に入力がある場合、トップページの行き先ボタンにメモのマークがつく。 | 高     | MVP   |
| F-05 | 日付       | 一週間分の日付が一覧でトップページに乗っている。毎週月曜日の 00:00 にリセット                                 | 高     | MVP   |
| F-06 | 日付       | 翌週の変更もできるように翌週一週間分の編集や確認もできるボタンがある                                         | 高     | MVP   |
| F-07 | 設定       | 一週間分の行先の固定設定が変更できる                                                                         | 高     | MVP   |
| F-08 | 通知       | 送る人・行先・メモが変わったら、変えた人以外の家族の端末にプッシュ通知を送る                                 | 高     | MVP   |

## 4. 非機能要件

- パフォーマンス: ページ読み込み 3 秒以内
- セキュリティ: 家族共通の合言葉（当初の案は Email + Google OAuth。家族だけで使うのでアカウントは作らないことにした）
- 可用性: SLA 99%
- スケーラビリティ: 同時接続 5 ユーザー

## 5. 制約条件

- 予算: 無料枠で完結
- 期間: 2 週間
- 技術: Next.js + Supabase + Vercel

## 6. 画面遷移

```
トップページ（今週／来週）
├── リスト一覧
│   ├── パパ/ママのボタンで操作
│   └── 行先を押すと詳細へ
├── 詳細（日ごと）
│   └── 行先の上書き・メモを記入
└── 設定
    ├── 曜日ごとの固定の行先
    └── 通知のオン/オフ
```

## 7. 決めたこと

- 1 日に記録するのは送る人 1 人（パパ/ママ/未定）。
- 「毎週月曜 00:00 にリセット」は、記録を消さずに「日本時間の今日を含む週（月〜日）」を表示することで実現する。
- 固定の行先を変えると、日ごとに行先を上書きしていない日にすぐ反映される。
